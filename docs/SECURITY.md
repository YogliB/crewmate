# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

The project is pre-1.0; security fixes are only provided for the latest `0.x` release.

## Reporting a Vulnerability

Report security issues by email to <me@yogev.dev> instead of using public issue
tracking. Please include the affected version, a description of the impact,
clear reproduction steps, and any proof of concept or logs that help us
understand the problem.

We will acknowledge receipt, triage the report privately, and follow up with
status updates as needed while we assess and remediate the issue. If a report is
accepted, we will coordinate a fix before public disclosure when possible. If a
report is declined, we will explain why where appropriate.
