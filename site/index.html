pickup

Watch GitHub PR review comments for @pickup mentions and reply with explanations or generated fixes.

Usage

PR references can be a full URL or shorthand like owner/repo/pull/4.

Features

  • Polls PR review comments on a configurable interval.
  • Replies to new @pickup mentions with explanations.
  • Optionally generates, commits, and pushes a fix when asked.
  • Tracks seen comment IDs so nothing is processed twice.
  • Supports full PR URLs or owner/repo/pull/N shorthand.

Try it

pickup watch owner/repo/pull/4
Built with Alpine.js and Pico.css. Source on GitHub.
